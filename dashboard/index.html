How implied value is computed — model radar-2

Every row is scored by one function of the snapshot figures. No protocol name is special-cased, and no row is hand-picked. Change the numbers in the sandbox below and the page recomputes every row live, so you can see what the model actually depends on.

Sandbox: recomputes the top row only, to show the model's sensitivity. The board itself always uses radar-2 as published.

TVL and seven-day growth come from the snapshot. Age is the time since the protocol was first listed, the best record of how long it has run with no token; an unlisted age uses 365 days. Maturity rises with age to two years, then eases back: a protocol that has run for years with no token is a little less likely to launch one. Breadth adds 3% per extra chain, capped at 8%. Confidence discounts a row where age or growth is unknown. Live-token protocols are set aside with their market caps shown, because a market price is a fact, not a model.

Reading this board

“Records no token” means DefiLlama's record carries no token for the protocol — it is not proof the protocol has none. A token may exist that its record does not carry. Farm plans are concrete steps with a cost and a time for each; they are not investment advice, and no step ever asks you to pay to claim anything. If a protocol's own page asks for a fee to claim, that is a scam.
